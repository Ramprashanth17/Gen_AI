**Welcome to the Gen_AI repository!** 🚀

This is a comprehensive collection of Generative AI projects, experiments, and learning resources. Whether you are looking to master Prompt Engineering, build Enterprise RAG systems, or explore hands-on Jupyter notebooks, you've come to the right place.

## 📂 Repository Structure

Here is what you will find inside:

| Project / Directory | Description |
| :--- | :--- |
| **🤖 [enterprise-knowledge-assistant](./enterprise-knowledge-assistant)** | A robust AI assistant designed to navigate and retrieve insights from enterprise-grade knowledge bases. Focuses on RAG (Retrieval-Augmented Generation) for business contexts. |
| **📚 [rag-learning-platform](./rag-learning-platform)** | A dedicated platform for learning and experimenting with RAG pipelines. Perfect for understanding how to connect LLMs to your custom data. |
| **✨ [PromptCraft_Project](./PromptCraft_Project)** | The art and science of Prompt Engineering. This project explores techniques to get the best outputs from Large Language Models. |
| **📓 [Gen_AI_Worked_Examples.ipynb](./Gen_AI_Worked_Examples.ipynb)** | A hands-on Jupyter Notebook filled with worked examples, code snippets, and practical experiments in GenAI. |

## 🛠️ Tech Stack

* **Languages:** Python 🐍
* **Core Concepts:** Generative AI, RAG, Prompt Engineering, LLMs
* **Tools:** Jupyter Notebooks, DevContainers
